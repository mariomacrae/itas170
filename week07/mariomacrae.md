Ask: which browser is fastest between 4 devices? I use several browsers on devices with varying degrees of RAM and the speed varies greatly.
Measure: the real thing, cheaply, more than once (4 devices, 3 browsers, same room. Initial WiFi speed test. Also check how much RAM the browser is using.)
Model: the agent builds a calculator/organizer of all these elements.
Calibrate: WiFi speed test, RAM usage.
Check: loading time for websites, responsiveness of device (is it running smoothly, does it lag?). Model predicts first and I check it after.
Decide: How far away from the router should I be, what sites to load.
What stays private: Network name, network credentials, IP address, my home address, any of my login credentials.
Compared with the turbine: Both experiments change one variable at a time (device, browser, site). Mine also has the same split between calibrating and checking. The turbine was tuned on one run (lab check 3: 316 rpm at 6.83 V) and checked against a different group's run (lab check 1: about 7 V, best near 9°). Mine is tuned one run at a time of one browser. 
What mine is missing: The turbine has more variables and is built from real physics. There is a lot less information about the router than the turbine.
What could stop it: Device memory overloaded, physical blockage, overloaded cache. I will clear the cache before measuring, cloe all other apps, and stay near the router so everything goes smoothly.
